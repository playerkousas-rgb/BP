# 設計審視紀錄 / Design review

B-P Atlas v1.2 · © SCOUT SYSTEM · 2026-11-10

## 目標與原則

以米白紙張、淡綠海色、鋼筆線條、路徑虛線、羅盤及近似中央比例尺表達野外地圖；用系統字體，避免徽章商標及未經確認的照片。UI 和 20 個行跡提供九種語言；部分歷史註記、組織名稱與來源標題仍沿用英文或原文，資料狀態要比裝飾更清楚。

## 實際審視紀錄

第 1–6 輪為 v1.0 的歷史紀錄，其中圖層和圖表配置由 v1.1 的第 7–10 輪取代；第 11–12 輪記錄本次 v1.2。

1. **地圖正確性與首次畫面**：在 1440×900、768×1024、390×844、320×700 的 headless Chromium 擷取畫面。最初有球面多邊形繞向反轉，造成海陸顛倒；加入 `rewind_world.mjs` 後重畫。小地區點、世界比例的站點及觸控範圍保持可見。
2. **佈局與互動**：修正桌面 grid 最小高度造成時間軸重疊；手機抽屜和切換鈕改為獨立固定，確保一次只顯示一個。320×568 短視窗縮小地圖並隱藏 teaser，時間軸不遮住地圖。修正抽屜關閉鈕和標籤重疊。長故事可在有鍵盤焦點的面板內捲動。
3. **可讀性與資料解釋**：補充 WAGGGS 排除、1907 前 WOSM、插值和 2025 估算標記，以及可讀來源頁；提高次要文字對比度，縮短英文標題避免窄版斷行。修正 1979 取消按鈕、keyboard focus 在重繪時流失，並加入資料載入失敗及重試介面。
4. **現況名錄與歷史證據分離**：新增可鍵盤操作的雙語名錄對話框；選取現況參考不改變時間或選中地圖。卡片分列早期團體、現行組織成立及 WOSM／前身認可年份，各有出處及衝突說明，未核實的舊年份只作研究線索。窄版隱藏名錄按鈕的裝飾圖示，避免 320px 表頭橫向溢出。
5. **入會資料優先與缺值**：名錄及卡片優先顯示 WOSM 所載年份與直接來源，已知年份爭議在數值旁提示並保留較早說法；歷史地圖仍只使用早期團體資料。人口和組織數圖表取消插值及連線，分別標示缺資料、約數及下限。第 3 輪的插值設計已被此改動取代。
6. **舊存檔與窄屏**：四項現行名錄空白及蘇丹詳細頁未能開啟時，舊 WOSM 存檔年份保持在有出處的說明中，不冒充現行名錄值；矛盾年份與認證／正式會籍分開註明。重新檢視 1440×900 及 320×568 中英文畫面：爭議提示出現在數值旁，詳細說明和來源可向下捲動；圖表保留點與 2024 年份內變動註解。

7. **v1.1／分離主題，第一輪**：對照用戶的四項要求和江山時序，把原人口小卡及大露營疊加層分成獨立人口頁和露營時序；B-P 的路線、故事、控制和相機保留。成員版圖與早期團體的資料分開，將所選年份的名錄累積數及歷史來源總數明確並列、標明口徑不可直接比較；加入來源年份選單。原本播放只跳名錄年份，會漏掉有統計但無名錄日期的 2018／2025，因此改為跳兩組有資料年份的聯集，不補造中間數據。
8. **v1.1／畫面複檢與修正**：實際檢視 1440×900、1024×768、768×1024、390×844、320×568 的中／英文 Chromium 畫面。320px 英文表頭曾橫向溢出，及短視窗的名錄計數與縮放鈕重疊：縮短按鈕版面、移動縮放鈕並檢查兩者不相交；人口圖改為隨容器重算 SVG 座標以保持窄屏刻度可讀，短視窗縮短重複引言，讓首次畫面看到數值。920–1000px 表頭亦曾溢出，已在 desktop 斷點加入精簡版。手機圖表與長故事須向下捲動，底部時間軸固定。
9. **v1.1／地圖幾何與二次審視**：2024 地圖顯示澳洲本土沒有着色；追查發現 Natural Earth 的澳洲本土與離島共用 ID，而舊程式只保留最後一個 feature。改為對同 ID 的所有 feature 上色，僅保留一個鍵盤控制，新增本土範圍及離島測試；香港、澳門等小地區圓點亦按相同年份配色及所選年描邊。重新檢視 1922／2024 成員、1979 取消事件和人口圖；來源和「非歷史快照」標示仍存在。其他地圖的全部歷史、邊界和幾何準確性仍未完成核實。
10. **v1.1／選年與焦點複檢**：320×568 手機抽屜選擇另一個來源統計年份後，重建卡片曾令捲動位置被瀏覽器重設，選單雖有焦點卻移出視野。現保留原捲動位置並確保選單留在抽屜內；中英文各測試 2018／2025、焦點與來源，並重新確認更換故事時仍會回到頂部。

Chromium 自動檢查涵蓋四主題、播放、來源、舊／新分享網址、鍵盤焦點、雙指觸控、名錄、抽屜、錯誤恢復和多種寬度。另對代表性的桌面／手機主題、對話框和來源頁執行 axe WCAG 2 A/AA 和 2.1 A/AA 自動規則；這不是全面 WCAG 認證，亦未代替實機 VoiceOver/TalkBack、Safari 或人工對比度檢查。手機小螢幕抽屜會遮住一部分地圖，這是保留底部時間軸的取捨。比較方式及未跑項目見 [一致性審計](CONSISTENCY_AUDIT.md)。

11. **v1.2／來源年份柱狀圖**：人口圖以每個有來源的人口年份建立等距類別柱，線性高度按實際來源數值比例繪製；等距不代表等時間間隔，缺失年份省略而非零。1907 年 20 人相對 6,000 萬小得不可辨，保留真實高度，以年份選單、柱的完整點擊區及時間軸提供操作。2025 年 estimated reach 採條紋區分，選年、約數／下限、來源、鍵盤和不插值的規則保留。
12. **v1.2／多語與響應式**：使用原生語言選單，保留中英並新增日、韓、法、西、印尼、葡萄牙、印地文。介面字串和 20 站行跡有譯文，176 項地區名以瀏覽器 CLDR／ICU 顯示，多地域項目保留完整範圍；未翻譯的詳細史料、來源標題或官方名稱沿用英文／原文並附提示和適當語言標籤。以 Chromium 檢查 320／390／1024 像素九種語言及四主題，另目視檢查日／印地文手機、法文桌面、印尼文平板；圖表與名錄可向下捲動。所有譯文仍需母語者和資料來源複核。

## 已知限制及未決事項

- 176 項現況名錄仍為研究草稿；總數與 WOSM 公布數字吻合，不代表一一對應或已核實。早期團體圖只暫定繪出 37 項；成員版圖另按 171 項現行 WOSM 年份累積，並非歷史成員快照；未知不等於沒有童軍。所有中文譯名、名稱更新、來源及歷史沿革仍須確認。
- 2027 大露營已在資料中，但時間軸上限為當年，未到 2027 前不能選取。
- 來源頁表格在窄螢幕可水平捲動；人口頁和故事內容可能需要垂直捲動。完全重合的紀錄會以引線及輕微位移分開；相近的高密度標記仍可能重疊，可放大查看或使用「下一站」。大露營虛線只表示已舉行地點的順序，並非真實旅行路線。
- mapshaper 報告 217 個未修復相交，雖已修正方向及通過大小／球面繞向檢查，不能宣稱全部拓撲無誤。
- 沙盒的靜態 HTTP 和預覽 host header 已測試；未實測公開 Vercel 部署或所有正式瀏覽器／裝置。分享圖片的絕對網址須在正式網域確定後設定。

## 版本及規則例外

- **V1 檔名例外**：原規格指定原生 ES module 路徑（例如 `js/app.js`）及固定 `index.html`。HTML 使用版本原稿 `bp-atlas_v1.2.html` / `credits_v1.2.html`，以 `scripts/sync-html.mjs` 產生穩定部署拷貝並由 guard 驗證。原規格指定的 JS/CSS/JSON 檔名保持不變；自家 JS/CSS 檔頭、HTML meta/title/footer、`js/state.js` 與 `package.json` 記錄版號。升版時同步更改並在 Git 歷史保留舊版。
- **L3 預設語言例外**：產品規格要求無 `lang` 時跟隨瀏覽器語言，優先於共享規則的中文預設；明確網址語言優先，儲存受阻也可切換。語言選單以各語言自稱列出九種選項；網址優先，否則依瀏覽器偏好選支援語言；儲存僅在瀏覽器未提供語言時作後備。
- **Vercel dist/install 例外**：本產品明確要求純靜態、無建置；不照搬共享範本的 `dist` / `--include=dev` 要求。Vercel 以根目錄和空 build/install 部署；瀏覽器測試的 Playwright 是本機開發依賴，不部署。
- **圖片水印範圍**：本網站不提供用戶圖片生成；favicon、應用 icon 和社交預覽是原創靜態 UI 資產，不是用戶生成成品或第三方作品。沒有宣稱它們含隱形水印；頁尾提供可見版權。若日後新增用戶成品圖片功能，須按共享 W2–W5 規則另行設計。
- **社交 metadata**：`og:image` / `og:url` 暫不填假域名；選定正式網址後補上絕對連結並實測。
