# 成員名錄與歷史地圖資料 / NSO data notes

B-P Atlas v1.2 · Research draft / 研究草稿 · 2026-11-10

這份筆記說明資料如何整理，不代表歷史、成員身份或使用權已經全面核實。完整出處及連結在 [`data/sources.json`](../data/sources.json)；每個地區的資料在 [`data/nso.json`](../data/nso.json)。

## 覆蓋和方法 / Coverage and method

- **現況名錄**有 176 個暫定所在地項目，手動整理自 2026 年 11 月查閱的 [WOSM 現況名錄](https://www.scout.org/where-we-work/scouting-worldwide)和[維基百科成員列表](https://en.wikipedia.org/wiki/List_of_World_Organization_of_the_Scout_Movement_members)。名錄不是即時同步。數目雖與 WOSM 公布的 176 個成員組織相同，並不證明每一項名稱、所在地、組織身份或日期均正確，也不證明兩種計數完全相同。
- 一項以所在地為單位，並非嚴格「一個國家等於一個組織」。部分是聯合會或跨地區組織；WOSM 在加拿大另列 [Association des Scouts du Canada](https://directory.scout.org/organizations/34/detail) 為特殊個案。本資料目前只列一個加拿大所在地；其卡片分別說明 Scouts Canada 的 1946 年名錄年份，以及特殊個案的名錄未列獨立入會年，沒有把 1946 自動套用到後者。這個額外的特殊個案不計入下列 176 項所在地的四個空白欄位。Curaçao 項亦註明其他覆蓋地區。須核實全部邊界與涵蓋方式。
- **早期團體圖**只使用 37 項暫有來源提及早期當地童軍團體的年份；其他 139 項的 `scoutingStart` 為 `null`，不會因此着色。這些資料不構成完整歷史地圖；空白不等於沒有童軍。17 項另保留舊樣本的未繪製線索。
- **成員版圖**是另一套繪法：只按現行名錄中 `wosmMembership.year ≤ 所選年` 的項目着色，名錄或新聞沒有優先年份的 5 項保持未知，不用 `scoutingStart`、`membershipYears` 或未核實線索填補。2026-11 資料的累積數在 1922、1950、1980、2000、2024 分別為 19、40、105、139、171；這是**現時名錄日期的累積數，不是各年實際 WOSM 成員總數**，也不能證明從該日期起連續存在。它沒有歷史邊界或已退出組織。顏色依日期分級，現代邊界只作示意；點擊地區可查逐項來源及已知爭議。
- 同一畫面另列 `data/membership.json` 在確切年份報告的組織／國家數（例如 1922 為 31、2024 年 8 月 10 日為 175，之後同年為 176）。來源統計與現時名錄的累積數範圍不同，**不得相加、替代或直接比較**。年份選單及播放包含兩組有記錄的年份；未有來源的年份不會以插值補出組織數。
- 所採年份是該來源記錄的**早期團體或活動可見年代**，不保證是最早一支或其正式成立日期。個別年份只表示「最遲當年已有記載」：例如菲律賓採 1911，而非將未經充分核實的 1910 說法當成成立年份。來源、定義及與當時／現代邊界的對應仍須逐項審查。
- 即使曾有早期團體，也不能推斷此後一直有童軍活動或連續 WOSM 會籍。本版沒有中斷時段或歷史國界資料，不能用現代行政區着色推論當時的主權或政治地位。
- 入會研究優先使用 **WOSM 的原始聲稱**，但不把名錄欄位當作必然的首次入會日期或獨立驗證。2026 年 11 月 10 日核對的 176 項中：169 項有 WOSM 名錄「Year of WOSM Membership」年份、1 項從名錄會籍歷史取得（黎巴嫩 1947）、1 項來自 WOSM 新聞（所羅門群島 2021），共 **171 項有現行名錄／新聞的優先年份聲稱**。西班牙、哥斯達黎加、烏拉圭、委內瑞拉的年份及歷史欄均空白；蘇丹名錄詳細頁（ID 181）當時回應 404，故現行詳細頁的年份未能核實。這些紀錄不是即時更新，WOSM 網頁亦可能更改。
- 上述五項的卡片另列 [WOSM 2010 年存檔統計表](https://web.archive.org/web/20100402025708/http://www.scout.org/en/around_the_world/countries/national_scout_organisations/some_statistics)的歷史聲稱（西班牙 1922、哥斯達黎加 1935、烏拉圭 1950、委內瑞拉 1937、蘇丹 1956）；不是現行名錄欄位或現行法人連續會籍的證明。哥斯達黎加的 [2007 年存檔](https://web.archive.org/web/20071012184832/http://scout.org/en/around_the_world/countries/national_scout_organisations/some_statistics)卻列 1925，兩個歷史說法尚未釐清。
- 每項核對的所在地 ID、名錄 ID、年份和依據保存在 [`research/wosm-directory-audit-2026-11.tsv`](research/wosm-directory-audit-2026-11.tsv)。`field` 是名錄年份欄；`history` 是年份欄空白但歷史文字有相關年份；`blank` 是兩欄均空白；`news` 是有日期的 WOSM 新聞；`unavailable` 是未能讀取名錄頁而非證明名錄空白。網站卡片直接連到有關 WOSM 詳細頁或新聞，並保留以前的其他來源年份。
- 所有年份包括直接名錄值仍屬研究草稿。前身、聯合會、認可和再加入可能不同；WOSM 的 `NSO since` 是組織成立／起始欄，**不是**入會欄。WOSM 與其他來源甚至同一頁可能互相矛盾，不能用優先來源抹去爭議。維基百科「組織成立」欄只保留作線索，不能當成第一支旅或現行組織成立年份。
- 參考擁有者的 [SCOUTWORLD](https://github.com/playerkousas-rgb/scoutworld/tree/bc645cf6fdd70043665f0bc7de277f8f8b14fbf5) 作組織名稱及比對線索；其 `founded` 混有不同概念，人口通常缺逐項日期和出處，不能直接作入會年、第一支旅或現時人口。沒有把該庫整表或程式批量複製入此專案；該庫當時沒有明示授權，重用前要先確認權利。
- 個別總會的人口數字尚未整理；缺少年份、定義或具體來源時不從 SCOUTWORLD、其他年份或總數推算。世界人口圖表只畫來源所載的獨立數據點，缺資料年份不顯示數值或連線。

## 欄位 / Fields

| 欄位 | 意義及編輯原則 |
|---|---|
| `id`, `iso2` | 穩定的所在地識別碼（主要採 ISO alpha-3 / alpha-2），不是 WOSM 組織 ID。 |
| `name`, `nso` | 中英所在地及現況組織名稱；中文可能是暫譯或保留原文。某些英文地名由 Unicode CLDR / ICU 提供，後經修改。 |
| `mapId`, `marker`, `small` | 對應現代 Natural Earth 底圖的數字 ID、經緯度及小地區顯示方式。香港和澳門使用小圓點，`mapId` 為 `null`；未繪製項目可以沒有座標。不能由底圖推斷歷史疆界。 |
| `scoutingStart`, `scoutingStartSources` | 早期團體圖暫採的當地團體年代及其直接相關出處；`null` 不繪製。不是必然的首支旅、入會年或連續活動證明；如只知最遲存在年份，必須在 `note` 說明。 |
| `organisationFounded`, `organisationFoundedSources` | 經個別研究後暫列的現行組織成立資料（雙語文字），與起步及入會分開。未知或衝突未釐清可為 `null`。目前 10 項填寫，並非其餘組織沒有成立年份。 |
| `wosmMembership` | 優先顯示的 WOSM 來源聲稱：`year` 可為 `null`；`basis` 為 `field`、`history`、`news`、`blank` 或 `unavailable`；`sources` 對應直接詳細頁或新聞。`note`／`noteSources` 記錄另有出處的沿革或矛盾，選定的明確年份爭議另以 `dispute: "year"` 提醒；沒有標記不代表已排除其他爭議。成員版圖按非空 `year` 累積；這並非歷史真相的保證。 |
| `membershipYears`, `membershipSources`, `membershipNote` | 保留原來的其他 WOSM／前身／二手認可或再認可年份、出處及沿革；數個年份並不表示沒有中斷，也不必然全屬同一現行法人。卡片另顯示與優先 WOSM 年份不同的年份，可能是另一階段或未解的衝突；未知可為 `[]`。 |
| `wikiFoundingLead` | 維基百科表格原有的「組織成立」欄值，只作**未核實線索**，不參與着色；該欄亦可能混用事件定義，沒有線索可設為 `null`。 |
| `startLead` | 舊樣本中缺乏足夠本地團體證據的年份及來源，只供研究，不參與着色。 |
| `note`, `sources`, `draft` | 雙語背景／爭議、整條紀錄相關出處與草稿標記。欄位各自的來源顯示在相應事實旁；整體來源在卡片底部。 |

要新增繪圖日期，先找能支持**當地童軍團體及年代**的資料，核對實際地域、該來源的聲稱與是否存在更早團體；不能只複製總會成立或入會年份。找不到支持時維持 `null`，把可能線索放在 `startLead` 或備註並列明來源。若資料只證明某年已有團體而不是成立年，應明言「最遲當年」；資料爭議應明示，不要隱藏不一致的說法。切勿把整份維基百科年份表或未授權的第三方資料表直接當成地圖開始年份。

## 個別需要注意的例子 / Selected conflicts

- **菲律賓**：1911 年 [BSA 手冊](https://www.gutenberg.org/files/29558/29558-h/29558-h.htm)收錄的信提到馬尼拉童軍小隊及領袖；地圖以此為「最遲 1911 年已有團體」的暫定證據，不是成立年。[維基百科](https://en.wikipedia.org/wiki/History_of_scouting_in_the_Philippines)的 1910 YMCA 旅說法仍待佐證；[菲律賓童軍總會](https://scouts.gov.ph/the-birth-of-the-boy-scouts-of-the-philippines/)提到 1912 年已有童軍和 1914 年首支菲律賓人旅。其入會年份亦有 WOSM 的 1946 與總會的 1947 之差。
- **香港**：1910 年訓練、1913 年正式旅及 1912 年貝登堡到訪是不同事項；地圖暫採 1913，仍須核對。**澳門及葡萄牙**：[葡萄牙童軍協會（AEP）歷史頁](https://www.escoteiros.pt/escoteiros-de-portugal/historia/)記載 1911 年澳門及 1912 年里斯本的早期團體，仍須獨立佐證；澳門 1983 年現行總會成立及 2017 年入會是另外兩件事。AEP 自述 1913 年成立、1922 年為創始成員；AEP 是現行葡萄牙聯盟的成員組織，年份不能直接視作該聯盟成立或入會年。
- **印尼**：WOSM 記載 1953 年會籍及 1961 年現行組織成立；維基百科列 1961 年入會。1912 年運動抵達不等於已核實當地第一支旅，因此不在早期團體圖着色。
- **斯洛文尼亞**：[WOSM 名錄](https://directory.scout.org/organizations/173/detail)年份欄及歷史列 1997；[斯洛文尼亞童軍總會](https://www.taborniki.si/svetovna-zveza/)卻表示 1994 年成為正式成員，兩者未釐清。**莫桑比克**：[名錄](https://directory.scout.org/organizations/135/detail)年份欄列 1999，歷史卻列 1990，並說現行聯盟於 1994 年成立；同頁本身矛盾。**巴布亞新畿內亞**：[WOSM](https://directory.scout.org/organizations/149/detail)列 1977，維基百科成員表列 1976。三者均顯示出處及不同說法，沒有擅自解決。
- **摩納哥及聖馬力諾**：WOSM 分別區分 1990 年認證與 [2014 年](https://www.scout.org/node/2339)、[2017 年](https://www.scout.org/node/3688)成員身份。**巴勒斯坦童軍協會**：WOSM [2017 年會議文件](https://wosmlzs3-bucket.s3.eu-west-1.amazonaws.com/2023-12/ConfDoc5_Baku2017_Membership_EN.pdf)將 1996 年無投票權的有條件承認與 2016 年正式會籍分開。**納米比亞**：舊統計及非洲區報告列 1990；其 2004 年通訊引述 WOSM 區分先前認證與正式會籍建議，1990 的確切性質仍待查證。**智利與利比里亞**：WOSM 分別列 1974／1965，同時記錄 1922 起較早的會籍歷史。**黎巴嫩**：年份欄空白，歷史列 1947 年黎巴嫩會籍及 1924 年與敘利亞共同認可。**印度**：1938 年會籍於 1950 年轉至現行組織；**葡萄牙**：WOSM 年份欄為 1922，但現行聯盟成立於 1982。這些數字不能都視作現行組織的首次加入或成立年。
- WOSM 的 [2022–25 年非洲區報告](https://treehouse.scout.org/system/files/2025-11/FR_AFR%20Triennial%20report%202022-2025-Web.pdf)與詳細名錄也列出不同會籍年份，例如布隆迪 1979／1978、佛得角 1992／2002、乍得 1960／1974、剛果民主共和國 1963／1969、津巴布韋 1960／1980，埃塞俄比亞報告列 1969／2000 而名錄記載 2002 年重新認可。佛得角名錄把 1992 描述為當地法律承認；不能推定它等於 WOSM 入會。塞舌爾在報告的加入年份欄為 2002；另一篇 [WOSM 報道](https://www.scout.org/node/3521)分別記載 2002 年獲認證和 2016 年正式會籍，報告是否指認證階段仍待核實。卡片並排列出來源，差異可能涉及不同會籍階段，仍需個別核實。
- WOSM 2010 年舊存檔與現行詳細名錄對博茨瓦納 1958／1968、多米尼加共和國 1930／1953、尼加拉瓜 1948／1956、巴拿馬 1950／1955、聖文森特及格林納丁斯 1990／1999 等所載年份也不同；不能僅因年份較早便判斷是否同一會籍。巴拿馬舊表另列 1924–1936 年會籍。**白俄羅斯**的 WOSM 歷史列 1998 年首次認可及 2010 年再認可，但維基百科成員表列 1989 年為入會年，差異仍待核實。
- **俄羅斯、敘利亞、伊拉克及阿富汗**：名錄或 WOSM 新聞指出有暫停、重新認可／重新加入；目前優先年份分別為 2004、2008、2017、2020，不能推論連續會籍。**日本與波蘭**：WOSM 所列 1922／1950 和 1922／1996 分別涉及中斷及再認可，並非連續會籍。波蘭的早期利沃夫（Lwów，今烏克蘭利維夫）及 1911 年華沙團體不能混為同一現代地區；地圖暫採華沙資料。
- **阿爾巴尼亞、馬里及塞舌爾**：WOSM 詳細頁與其他資料對成立／認可日期有不同說法；卡片保留衝突，未作無根據的統一。**加拿大**的特殊個案和**澳洲、印度、比利時、英國、馬耳他**的不同「最早」定義亦須進一步核對。**美國**的 1909 年 Pawhuska 團體有獨立來源，但最早一旅的不同說法仍有爭議。
- **所羅門群島**：WOSM 提及瓜達爾卡納爾島 1928 年的童軍活動，並不單憑此確定第一支旅；暫不在早期團體圖着色。**阿根廷**的 1908 年資料涉及小隊，**希臘**及**斐濟**的來源範圍和年份亦待釐清，故早期團體圖暫不繪製。

## 介面及網址 / Interface and links

名錄按鈕開啟現況參考卡：`?nso=PAK&ref=1&year=1907` 不改變所選年份、鏡頭或歷史地圖選取，亦不表示現行組織在 1907 年已存在。拖動時間軸時該參考卡保持開啟；地圖按目前選中的成員／早期團體資料集更新。沒有 `ref=1` 的舊 `?nso=HKG` 和 `mode=spread` 仍以 `scoutingStart` 選取；明確 `mode=members&nso=PAK` 才依 `wosmMembership.year` 選取，可能將年份推至該日期。舊 `panel=chart` 遷移至獨立人口圖表；舊大露營／組織疊加開關由獨立主題和來源年份選單取代，舊 `jamboree=<id>` 連結仍可開啟該事件。搜尋和中斷時段視覺化仍屬未來功能。

修改後執行 `npm run check` 和 `npm run test:browser`。結構與 UI 測試不會判斷來源是否真能支持聲稱；正式發佈前仍須逐條核實，見 [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)。Wikipedia 及 Unicode 的授權、作者和改動說明見 [CREDITS.md](../CREDITS.md)。
