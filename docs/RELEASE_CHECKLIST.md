## 歷史與覆蓋

- [ ] 以 WOSM 最新正式資料逐項核對 176 個暫定所在地項目、名稱、組織身份、所在地及地圖對應；核實聯合會、跨地區組織與加拿大特殊個案如何計數。總數吻合不等於清單已驗證；不要將未收錄或未着色解讀為沒有童軍。
- [ ] 核對 37 個已繪製 `scoutingStart` 的資料是否真的描述當地早期團體及年份；區分成立年份與「最遲已有團體」的證據，確認來源連結及雙語內容。其餘 139 項和 17 個舊線索只有找到足夠相關證據才新增着色，不能只用總會成立或 WOSM 加入年。
- [ ] 核實各項 `organisationFounded`、`wosmMembership`、`membershipYears`、欄位專屬來源及維基百科線索。171 項有現行 WOSM 名錄／新聞的優先年份不等於已完成獨立歷史核實；四項名錄欄空白、蘇丹詳細頁 404。五項均另有 WOSM 舊存檔年份，但不能假定與現行組織會籍相同；哥斯達黎加的舊存檔甚至互有分歧。釐清前身、認證、重加入、間斷會籍、特殊個案及各來源矛盾；沒有證據便保持未知。見 [逐項核對表](research/wosm-directory-audit-2026-11.tsv)。
- [ ] 特別核對香港 1910 訓練／1913 正式旅／1912 到訪日期、葡萄牙童軍協會所述澳門 1911 及里斯本 1912 早期團體（與澳門總會 1983／2017 等不同事件）、菲律賓 1910／最遲 1911／1914 及入會 1946／1947、英國 1908 常設早期旅、波蘭早期地點和 1996 重加入，以及巴基斯坦目前未知的首支旅年份。
- [ ] 核對全部 20 個行跡的地點、年月、用詞、史料及當時地名；尤其軍旅站點的具體座標／年份、香港、婚禮、基維爾和 1937 年。軍旅敘事繼續以 WOSM 公開介紹為範圍，文字改寫而非照抄。
- [ ] 用主辦／WOSM 一手資料核對 26 屆大露營與 1979 取消的年份、地點、座標和參加人數。未到的 2027 是計劃，不描述為已舉行；未知值保留 `null`。
- [ ] 核對全部統計點及來源能否支持年份、數值、精度與人數口徑，補齊足夠的可靠一手資料。2013、2002 和 1985 目前包括二手來源；2025 是 estimated reach（非普查）、1907 是 WOSM 成立前的營地，國家與成員組織口徑不可直接對比。釐清 WOSM 2023 公開資料「超過 5,700 萬」與其後公布的 2023 登記普查「超過 5,140 萬」之關係。缺數據年份不推算或連線；個別總會人口尚未整理，將來新增時必須提供年份、定義及欄位出處。
- [ ] 核定有爭議邊界所用 Natural Earth 版本及文字；逐一檢查簡化後的幾何與 mapshaper 未修復相交。底圖是現代邊界，不能暗示是歷史邊界。
